# Continuous Production Leadership Model

> **Supporting model only.** The authoritative project organization is
> `docs/COMMANDER-OPERATING-ORGANIZATION.md`.

## Production Organisation

| Member | Responsibility | Today's objective | Today's work | Reports to | Failure response |
|---|---|---|---|---|---|
| **Commander** | Overall direction | 5 signups + 1 sale | Prioritise, delegate, evaluate and reallocate | Owner only at a genuine boundary | Move to the highest-impact next task |
| **Social Planner** | Facebook angles, hooks and links | Four measurable traffic actions | Build webinar, objection, educational and conversion angles | Commander | Replace an ineffective angle |
| **Facebook Publisher** | Facebook Page publications | Generate qualified webinar traffic | Publish approved packages, save receipts and monitor comments | Social Planner and Commander | Stop if session or Page access is missing |
| **OLSP Observer** | Backoffice outcomes | Verify signups, sales and revenue | Collect same-day observations continuously | Commander | Mark stale or incomplete evidence invalid |
| **GA4 Observer** | Traffic and UTM path | Verify source → landing page → outbound click | Read GA4 and persist read-only evidence | Commander | Make no attribution claim without current evidence |
| **Funnel Operator** | Article, CTA and MegaLink | Remove conversion-path friction | Review and repair the approved local funnel | Commander | Stop that path and reallocate resources |
| **Community Scout** | Reddit, groups and forums | Find demand and compliant participation | Monitor discussions and collect questions | Commander | Stop when identity, permission or rules block action |
| **Email Operator** | Email campaigns | Generate measurable webinar traffic | Prepare and send only measurable campaigns | Commander | Hold if response data is absent |
| **Content/SEO Operator** | Articles and search traffic | Build continuing demand | Produce objection and search-question content | Commander | Do not produce content unrelated to today's funnel |
| **Video Operator** | OpenMontage video | Prove one publish-ready video | Inactive until a reliable workflow is verified | Commander | Keep video out of production |
| **Technical Delivery Operator** | Astro build and Cloudflare Worker | Get approved changes live | Build and verify production | Commander | The Worker version-upload invoker remains an open defect |

## Continuous Production Cycle

Commander does not wait for a clock time. Every completed task releases its
resource immediately:

1. Commander evaluates current evidence.
2. Commander selects the highest-impact task.
3. Work is delegated to one or more agents.
4. Parallel agents work simultaneously.
5. The first completed agent returns its result.
6. Commander verifies the result immediately.
7. A usable result is followed by the next task.
8. A failed result moves to repair or the next channel.
9. The cycle continues without waiting for the next scheduled hour.

Social planning can run while OLSP outcomes are collected. Community research
can run while Facebook publishing is in progress. GA4 can measure the prior
publication while Content prepares the next objection response.

## Platform Behaviour

### Facebook

- Leave enough interval for each post to produce its own evidence window.
- Publish the next post when the previous post has produced an observable traffic
  or engagement signal, not merely because the clock reached a slot.
- Answer comments containing questions or purchase intent.
- Never repeat the same hook or text as a duplicate.
- If a post produces outbound clicks or signups, allocate the next resource block
  to that angle.

### Facebook Groups

- Read the group context and rules first.
- Answer the question directly rather than attaching a link to every comment.
- Add a link only when it solves the stated problem.
- Do not post where promotion is prohibited.

### Reddit and Forums

- Use Reddit and forums to find demand, objections and the language users use.
- Participate conversation-first, never as mass posting.
- Stop when action would require false identity, rule-breaking or spam.
- Convert recurring questions into hooks and article briefs.

### Email

- Send only when click and response measurement is available.
- Route measurable campaigns to the webinar page.
- Do not send an unmeasured batch merely to appear active.

## Resource Reallocation

- Webinar traffic without registrations moves resources to funnel repair.
- Registrations without sales move resources to the MegaLink and offer path.
- Facebook without traffic moves the next work block to community and email work.
- A recurring community question becomes a Content and Social Planner input.
- If GA4 or Worker deployment is not live-verified, attribution claims stop while
  approved traffic acquisition continues.

## Leadership Rule

After every new event Commander asks:

> What work moves the project fastest toward five signups and one sale now?

When the answer changes, resource allocation changes immediately. Commander
leads the system that creates traffic, registrations and sales; it does not merely
manage a posting calendar.
